# Prabu Office

Aplikasi Prabu Office versi Vercel. Backend Node.js Functions, database TiDB Cloud, dan penyimpanan file memakai Vercel Blob.

HTML aplikasi tidak diubah. Fungsi login, sesi multi-device, transaksi, penomoran dokumen, rekap, bukti bayar, SPT, reminder pajak, dan draf WA tetap sama.

Panduan deploy lengkap ada di [README-VERCEL.md](README-VERCEL.md).
